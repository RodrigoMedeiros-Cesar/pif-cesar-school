a) Efeito de if (x = 0)

Variável x: Recebe o valor 0 (atribuição).

Bloco executado: Não executa. Como o resultado da atribuição é 0, a condição é avaliada como falsa. O operador de comparação correto seria ==.

b) Interpretação de valores numéricos

0 (zero): Avaliado como falso (ignora o bloco).

Diferente de 0: Avaliado como verdadeiro (executa o bloco).

c) Análise de if (x = -5)

Resultado: Será executado.

Justificativa (ANSI C): Atribui -5 a x. Como o valor retornado (-5) é diferente de zero, o padrão ANSI C o interpreta como verdadeiro.
