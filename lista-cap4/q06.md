Explicação: São exibidas múltiplas mensagens porque o código utiliza estruturas de if independentes e separadas, em vez de uma cadeia encadeada. Para idade = 65, as condições idade >= 60, idade >= 18 e idade >= 12 são todas verdadeiras, fazendo com que o programa execute os três blocos printf em sequência. O else final pertence apenas ao último if (idade >= 12), que sendo verdadeiro faz com que o else seja ignorado.

b) Comandos if independentes: Cada instrução condicional é avaliada isoladamente. O programa verifica todas as condições uma a uma, permitindo que múltiplos blocos de código sejam executados caso várias condições sejam verdadeiras em simultâneo[cite: 6].

Cadeia else-if: As condições são avaliadas de forma sequencial e em cadeia. Assim que o programa encontra a primeira condição verdadeira, ele executa o bloco correspondente e ignora completamente todas as restantes condições e ramos abaixo dela (são mutuamente exclusivos).

c) int idade = 25;

if (idade >= 60) {
    printf("Idoso\n");
} else if (idade >= 18) {
    printf("Adulto\n");
} else if (idade >= 12) {
    printf("Jovem\n");
} else {
    printf("Criança\n");
}
