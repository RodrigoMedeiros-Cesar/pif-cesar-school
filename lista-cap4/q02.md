a) Como $x = 15$, a primeira condição if (x > 10) é verdadeira ($15 > 10$), fazendo o programa entrar no bloco interno. Devido à ausência de chavetas e à regra do dangling-else, o else associa-se ao segundo if (if (y > 10)). Como $y = 5$, a condição $5 > 10$ é falsa, fazendo o programa saltar o printf("Opção A\n") e executar imediatamente o bloco do else, imprimindo "Opção B"

b) Na linguagem C, a regra oficial estipula que uma cláusula else sem blocos delimitados por chavetas ({}) associa-se sempre ao if mais próximo no código que ainda não possua um else correspondente, independentemente da indentação ou do espaçamento visual feito pelo programador.

c) int x = 15, y = 5;

if (x > 10) {
    if (y > 10) {
        printf("Opção A\n");
    }
} else {
    printf("Opção B\n");
}
